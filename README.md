# NovaTop — متجر باقات الألعاب

متجر عربي RTL متجاوب، مبني باستخدام HTML وCSS وJavaScript دون إطار عمل. يصلح كمشروع عرض أمام الأستاذ أو نقطة بداية لمتجر فعلي.

## التشغيل
1. افتح `index.html` في المتصفح، أو شغّل مجلد المشروع باستخدام Live Server في VS Code.
2. لا يلزم تثبيت مكتبات أو تشغيل خادم لمعاينة الواجهة. خط Cairo يُحمّل من Google Fonts عند الاتصال بالإنترنت؛ يوجد خط بديل عند انقطاع الإنترنت.

## الميزات
- صفحة رئيسية متجاوبة للحاسوب والهاتف.
- قائمة ألعاب ومنتجات مع تصفية وبحث وترتيب.
- سلة تحفظ المنتجات في `localStorage` وتدعم زيادة الكمية وحذف العناصر.
- نموذج بيانات العميل/معرّف اللاعب وطلب عبر واتساب.
- قسم العروض، خطوات الطلب، أسئلة شائعة، وقائمة هاتف.

## التعديل قبل النشر
- **رقم واتساب:** افتح `script.js` وعدّل `STORE_WHATSAPP` إلى رقمك الدولي دون علامة `+`، مثل `905XXXXXXXXX`. رقم المثال الموجود افتراضي ويمنع إرسال الطلبات حتى تغييره.
- **المنتجات والأسعار:** عدّل مصفوفة `products` في `script.js`. جميع الأسعار افتراضية ولأغراض العرض فقط.
- **الاسم والعلامة التجارية:** غيّر `NovaTop` و`NOVATOP` في `index.html`، ثم الألوان في `styles.css`.
- **عملة الأسعار:** قيمة `CURRENCY` داخل `script.js` حاليًا `TRY` (الليرة التركية).

## حدود الإصدار
هذه واجهة Front-end فقط؛ لا يوجد حساب مستخدم أو قاعدة بيانات أو لوحة تحكم أو بوابة دفع حقيقية أو تنفيذ آلي لعمليات شحن الألعاب. عند الضغط على «إرسال الطلب» يُفتح واتساب برسالة مُعدّة، ويجب على العميل إرسالها بنفسه؛ لا تُحفظ معلومات النموذج في خادم الموقع. للإطلاق التجاري، تحتاج إلى صلاحية بيع/إعادة بيع المنتجات وفق قواعد ناشري الألعاب، وشروط استخدام وسياسة خصوصية ملائمتين، وإدارة للطلبات وأسعارًا حقيقية، وخلفية آمنة وربط موثوق مع مقدم دفع مرخّص إن أردت الدفع عبر الموقع. لا تطلب كلمات مرور حسابات اللاعبين.
